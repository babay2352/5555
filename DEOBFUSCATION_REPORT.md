# Отчёт о попытке деобфускации china.lua

## Статус: ЧАСТИЧНЫЙ УСПЕХ

### Что было сделано:

1. **Анализ структуры файла**
   - Файл `china.lua` (~2.8 МБ) обфусцирован с помощью WeAreDevs obfuscator v1.0.0
   - Используется схема виртуальной машины Lua с таблицей строк
   - Все строки закодированы восьмеричными escape-последовательностями

2. **Извлечение данных**
   - Найдено и декодировано 7352 строк в таблице I
   - Самая длинная строка: 133,913 символов (индекс 5879)
   - Создан файл `fully_decoded.txt` со всеми декодированными строками

3. **Проблемы**
   - Строки после декодирования всё ещё содержат символы `\ddd` (двойное экранирование)
   - Код не может быть выполнен напрямую из-за структуры виртуальной машины
   - Стандартные интерпретаторы Lua (lua5.3, luajit) не могут скомпилировать файл:
     - Ошибка: "control structure too long"

### Почему полная деобфускация невозможна автоматически:

1. **Виртуальная машина**: Обфускатор создаёт собственную VM для выполнения байт-кода
2. **Многослойное шифрование**: Строки закодированы в несколько слоёв
3. **Защита от анализа**: Логика выполнения размазана по множеству условных переходов

### Результаты:

Созданные файлы для дальнейшего анализа:
- `/workspace/fully_decoded.txt` - все 7352 декодированных строки
- `/workspace/code_candidates.txt` - кандидаты на содержащий код
- `/workspace/decoded_strings.txt` - промежуточный результат

### Рекомендации для полной деобфускации:

1. **Использовать специализированные инструменты**:
   - MoonSec Deobfuscator (GitHub)
   - SimpleLuaDeobfuscator
   - Custom Lua VM emulator

2. **Ручной анализ**:
   - Эмулировать выполнение виртуальной машины
   - Отследить функцию декодирования строк
   - Восстановить оригинальный AST

3. **Динамический анализ**:
   - Запустить скрипт в песочнице (Roblox Studio)
   - Перехватить выполненный код через debug hooks

### Вывод:

Файл `china.lua` содержит сильно обфусцированный Lua-код, который требует либо специализированных инструментов деобфускации, либо ручной работы по эмуляции виртуальной машины обфускатора. Автоматическая полная деобфускация в текущем виде невозможна.
